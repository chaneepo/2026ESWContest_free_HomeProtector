# 라즈봇 제어 래퍼

[프로젝트 홈](../../README.md) · [상위 안내](../README.md)

설치된 `raspbot` 드라이버를 감싸 이동 종류·속도·시간 제한과 센서 읽기를 제공합니다.

## 파일과 하위 폴더

| 파일·폴더 | 내용 |
|---|---|
| [__init__.py](__init__.py) | Python 패키지 진입점 |
| [controller.py](controller.py) | 속도·시간 제한과 I2C 드라이버 래퍼 |

## 사용 방법

[상위 실행 안내](../README.md)를 통해 서버 또는 시험 스크립트에서 사용합니다. 단독 웹 서버는 아닙니다.

## 알아둘 점

`start_motion()`은 서버 내부용입니다. 단독 호출하면 대기·정지를 관리하지 않으므로 애플리케이션에서는 `pulse()`나 서버를 사용합니다. STOP 시도와 실제 모터 정지는 구분해야 합니다.
