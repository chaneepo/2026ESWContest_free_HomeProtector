# CARE-PACK의 SO-ARM101

[프로젝트 홈](../README.md) · [팔·모터 코드](../motor/README.md)

시연 영상과 영상별 설명을 정리하는 폴더입니다. 현재 이 폴더에는 안내 문서만 있으며 영상 파일이나 시연 결과 링크는 등록되어 있지 않습니다.

## 영상 추가 시 기록할 내용

| 항목 | 설명 |
|---|---|
| 제목·촬영일 | 어떤 버전의 어떤 시험인지 |
| 제어 방식 | 수동 / 고정 시퀀스 / 리더암 추종 / 자율 / 시뮬레이션 구분 |
| 사용 장비 | 라즈봇·팔·카메라·센서 구성 |
| 시험 조건 | 물품·위치·성공 판정 기준·운영자 개입 |
| 결과·제약 | 실제 측정값과 실패·미검증 사항 |
| 코드 | 영상에 사용한 커밋 또는 버전 |
| 영상 링크 | 저장소 파일 상대 경로 또는 공개 권한을 확인한 링크 |

## 작성 원칙

시뮬레이션 영상이나 사람이 리모컨으로 조작한 영상을 실제 자율 시연으로 표시하지 않습니다. 실제 자율화가 완료되면 해당 영상과 측정 결과를 따로 추가합니다.

대용량 영상은 저장소 용량을 고려해 외부 링크 또는 별도 파일 관리 방식을 정한 뒤 등록합니다. 공개 전에 얼굴·비밀번호·내부 화면 등 불필요한 개인정보가 포함되지 않았는지 확인하세요.
