# 서버 측 장치 연결 도우미

[프로젝트 홈](../README.md) · [상위 안내](../README.md)

Pi·카메라 주소 구성, 요청 중계, 타임아웃과 오류 응답 처리를 관리합니다.

## 파일과 하위 폴더

| 파일·폴더 | 내용 |
|---|---|
| [deviceProxy.ts](deviceProxy.ts) | 카메라 서버 주소·상태 요청 |
| [raspbotProxy.ts](raspbotProxy.ts) | 라즈봇 주소·출처 검사·요청 중계 |

## 사용 방법

[장치 API](../app/api/device/README.md)에서 가져와 사용합니다. `.env.local`은 서버 재시작 후 반영됩니다.

## 알아둘 점

라즈봇 주소에는 자동 기본값이 없습니다. 카메라 도우미에는 기존 기본 주소가 남아 있으므로 항상 `CAMERA_API_URL`을 명시하세요. 출처 검사와 운전 토큰만으로 인터넷 공개용 인증이 완성되는 것은 아닙니다.
