# 웹 공개 정적 파일

[프로젝트 홈](../README.md) · [상위 안내](../README.md)

웹 아이콘과 링크 공유용 이미지를 제공합니다.

## 파일과 하위 폴더

| 파일·폴더 | 내용 |
|---|---|
| [favicon.svg](favicon.svg) | 웹 아이콘 |
| [og.png](og.png) | 링크 공유 미리보기 이미지 |

## 사용 방법

`favicon.svg`, `og.png`는 각각 `/favicon.svg`, `/og.png`로 접근합니다. 공유 메타데이터는 [app/layout.tsx](../app/layout.tsx)에 있습니다.

## 알아둘 점

이 폴더의 파일은 웹에 공개될 수 있으므로 비밀번호·설정 백업·비공개 로그를 넣지 마세요. README 배너는 [docs/assets](../docs/assets/README.md)에 있습니다.
