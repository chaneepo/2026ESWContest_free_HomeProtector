# 팀 인터페이스 가이드

## 1. 목적

프론트엔드, 백엔드, 비전, 로봇, 센서 팀이 같은 상태·ID·단위를 사용하도록 경계를 정의한다. 이 문서는 조직도를 정하는 문서가 아니라 통합 시 깨지기 쉬운 계약을 관리하는 실무 기준이다.

## 2. 담당 영역

| 팀 | 소유 범위 | 반드시 제공할 것 |
|---|---|---|
| 프론트엔드 | 운영 화면, 사용자 입력, 상태 표시 | API 요청, 오류 UI, mode 표시 |
| 백엔드/Core | API, 상태기계, 영속화, 작업 조정 | 버전 계약, idempotency, 이벤트 |
| 비전 | marker/객체 검출, pose, 보정 | 좌표계, 신뢰도, 보정 버전, 시간 |
| 로봇 | SO-ARM101 adapter, 동작, 안전 상태 | 명령 ACK/완료, pose, 오류 코드 |
| 센서/ESP32 | 적재·도킹 측정 | 단위, 품질, 샘플 시간, 연결 상태 |
| 이동 로봇 | 향후 Razbot 배송·도킹 | 위치, 작업 handoff, 도킹 결과 |
| QA/안전 | 시나리오, KPI, 위험 검토 | 시험 결과, 릴리스 차단 조건 |

## 3. 공통 계약 규칙

- 모든 요청과 결과에 `requestId` 또는 추적 ID를 사용한다.
- 작업은 `jobId`, 물품은 `itemId`, 로봇 명령은 `commandId`로 연결한다.
- 길이는 m, 각도는 rad 또는 deg 중 하나를 계약에서 고정하고 필드에 단위를 명시한다.
- 시간은 UTC ISO 8601로 전송한다.
- enum은 문자열로 전달하고 의미를 바꾸지 않는다.
- 알 수 없는 enum을 받았을 때 즉시 crash하지 않고 오류 상태로 표시한다.
- API 성공, 명령 접수, 동작 완료, 물리 검증 성공을 별도 상태로 둔다.

## 4. 통합 매트릭스

| 제공자 → 소비자 | 계약 | 확인 항목 |
|---|---|---|
| Frontend → Backend | 작업/수동 명령 요청 | 중복 클릭, 입력 검증, 409 처리 |
| Backend → Frontend | 상태·이벤트 | 재연결, 순서, 오래된 상태 무시 |
| Core → Vision | detect 요청 | 대상 물품, 제한 시간, 좌표계 |
| Vision → Core | detection 결과 | frame, pose, confidence, calibration |
| Core → Arm | 로봇 명령 | command ID, timeout, 작업 공간 |
| Arm → Core | ACK/완료/오류 | 실제 완료 시점, final pose |
| Core → Sensor | 검증 요청 | 기준값, 측정 창, job/item 연결 |
| Sensor → Core | 측정/판정 | 단위, 품질, timestamp |

## 5. 변경 관리

1. 계약 변경은 문서와 TypeScript/OpenAPI 스키마를 함께 수정한다.
2. 필드 추가는 가능한 한 하위 호환으로 진행한다.
3. 필드 삭제·enum 의미 변경은 API 버전을 올린다.
4. mock과 실장비 adapter에 동일한 contract test를 실행한다.
5. 좌표계, 단위, 타임아웃 변경은 비전·로봇·Core가 함께 승인한다.
6. UI 문구와 실제 재시도 정책처럼 불일치가 발견되면 issue와 담당자를 지정한다.

## 6. 통합 회의 체크리스트

- 이번 빌드가 SIMULATION인지 REAL인지 명시했는가?
- 새 endpoint/command/event code가 문서화되었는가?
- 정상·타임아웃·오프라인·취소 응답 예시가 있는가?
- request 중복 전송 시 물리 동작이 한 번만 실행되는가?
- 카메라와 로봇이 같은 calibration version을 사용하는가?
- 센서 검증 기준값과 측정 창이 합의되었는가?
- 비상정지 이후 어떤 팀도 추가 운동 명령을 보내지 않는가?
- 통합 실패를 jobId로 처음부터 끝까지 추적할 수 있는가?

## 7. 완료 정의

기능은 화면에서 동작하는 것만으로 완료되지 않는다. 계약 테스트, 실패 시나리오, 이벤트 추적, 실제 장치 확인, 문서 갱신까지 끝나야 해당 통합 항목을 완료로 본다.
