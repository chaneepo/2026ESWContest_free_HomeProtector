## 사용 방법

다른 웹 모듈에서 `@/types`를 import합니다. 타입 확인은 저장소 루트에서 `(cd frontend && npx tsc --noEmit --incremental false)`로 수행합니다.

## 알아둘 점

타입 선언만으로 API 요청의 런타임 유효성을 검증할 수 없습니다. 실제 서버 입력 검증은 별도로 유지해야 합니다.
