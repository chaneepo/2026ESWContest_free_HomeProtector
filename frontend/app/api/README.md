## 사용 방법

현재 구현은 [장치 API](device/README.md)입니다. 웹 개발 서버와 함께 실행됩니다.

## 알아둘 점

이 폴더는 라즈봇·카메라 연결을 위한 장치 API를 담당합니다. DB 상태 확인은 별도 [백엔드](../../../backend/README.md)의 `/health`를 사용하고, 물품·작업 CRUD API는 업무 데이터 연동 단계에서 확장할 계획입니다.
