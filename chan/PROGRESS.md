마지막 갱신: 2026-09-02

- 실기모드의 화면별 임시 권한, 5초 heartbeat 만료, 기본 잠금 적용.
- 공통 안전 클라이언트로 Pi UI와 통합 React 리모컨의 제어 규칙 통일.
- 제어 서버 31개·브라우저 클라이언트 8개·자율 시뮬레이터 9개 테스트 통과.
- `autonomy/`에 라인 판단·도킹·집기·놓기·검증의 시뮬레이션 추가. 실물 어댑터 연동은 개발 로드맵에 포함.
- 프로젝트 소개·아키텍처·기능 안내·실행법·개발 로드맵 문서화.
- `can0.service` 실행 실패 기록. 사용 전 CAN 버스·핀·비트레이트와 서비스 설정 확인 필요.
- [안전 점검 기록](SAFETY_REVIEW.md), [자율 작업 시뮬레이터](../autonomy/README.md) 참고.

아래는 이전 시점의 기록이며 IP·테스트 수·운전 규칙은 최신 문서를 우선합니다.

## 장비와 접속 확인

- Raspberry Pi 5 Model B Rev 1.0 확인
- Ubuntu 24.04 LTS 확인
- Mac에서 Raspberry Pi로 SSH 접속 확인
- Raspberry Pi 실행 경로를 `/home/tracelab/chan`으로 구성
- 기존 `/home/tracelab/raspbot_ws/venv` 가상환경 재사용
- `raspbot==0.1.2` 드라이버 패키지 확인

## 하드웨어 연결 확인

- Raspbot V2와 Raspberry Pi를 I2C로 연결
- SDA: 노란색 선 → 물리 3번 핀(GPIO2)
- SCL: 초록색 선 → 물리 5번 핀(GPIO3)
- GND: 검은색 선 → 물리 6번 핀
- `/dev/i2c-1`에서 제어보드 주소 `0x2B` 검출
- 라인 센서와 초음파 거리값 수신 확인

## 안전 구동 확인

- 네 바퀴를 바닥에서 띄운 상태에서 최초 시험 수행
- 속도 40, 0.1초 전진 명령 완료
- 이동 명령 종료 시 자동 `stop()` 호출 확인
- 실제 웹 UI에서 이동 및 회전 API 정상 응답 확인

배터리를 다시 충전하거나 배선을 변경한 후에는 속도 20, 0.1초부터 바퀴
방향과 자동 정지를 다시 확인해야 합니다.

## 구현 완료

- 데모 모드: 하드웨어 없이 UI와 API 확인
- 센서 점검 모드: 실제 센서 사용, 모든 이동 명령 차단
- 실제 하드웨어 모드: 짧은 펄스 방식으로 바퀴 제어
- 전진, 후진, 좌우회전, 좌우 평행이동
- 방향키와 `WASD/QE` 키보드 운전
- `REMOTE SETTING` 키보드 리모컨 ON/OFF 버튼
- IPv4 주소가 바뀌는 환경을 위한 IPv6 웹 서버 지원
- 속도와 1회 이동 시간 제한
- STOP 버튼 및 스페이스바 정지 명령
- 초음파 거리 및 4채널 라인 센서 표시
- 좌우회전 예상 각도 `1~180°` 직접 입력
- Mac 원본을 Raspberry Pi로 배포하는 스크립트
- 컨트롤러와 서버 단위 테스트 9개

## 충전 점검 기록

- Raspbot V2 전용 충전기 규격: `8.4V 2A DC4017`
- 충전할 때 Raspbot 주 전원 스위치는 `OFF`
- 충전 상태는 제어보드가 아니라 충전기 본체 LED로 확인
- 빨간색은 충전 중, 초록색은 충전 완료
- USB-A 케이블과 Raspberry Pi USB-C 어댑터는 Raspbot 배터리 충전용이 아님
